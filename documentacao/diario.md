# Diário do Projeto

## Sprint 1 - Importação e preparação dos dados

### Objetivo

Iniciar o projeto de análise de vendas importando a base para o Power BI e verificando a qualidade dos dados.

### Atividades realizadas

- Estrutura do projeto criada.
- Repositório criado no GitHub
- README inicial criado.
- Base de dados importada no Power BI.
- Tipos de dados revisados.
- Datas convertidas utilizando "Usar localidade".
- Qualidade dos dados analisada.

### Observações

- A coluna Sales representa o faturamento.
- A coluna Profit representa o lucro.
- Order Date e Ship Date vieram como texto e precisaram ser convertidas para Data.
